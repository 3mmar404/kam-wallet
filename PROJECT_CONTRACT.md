# KAM project contract
Arabic RTL, Egyptian EGP, local-only financial data, no account, no backend. Amounts stored as integer piasters. No fake entries. Expected and actual are distinct. Transfers net zero. Scenario data isolated. Never claim production completeness without tests and deployment verification.

## Delivery status
This repository contains an offline-first dependency-free functional build. The requested React/TypeScript/Dexie stack and full production acceptance suite are not yet implemented. Do not describe this as the completed specification.
