# كام؟ KAM

تطبيق محفظة مالية محلي باللغة العربية، يعمل في المتصفح.

## تشغيل ويندوز

فك الضغط، ثم اضغط مرتين على `START-WINDOWS.bat`. سيفتح المتصفح على http://localhost:8080/ . اترك نافذة التشغيل مفتوحة. لا يحتاج Python أو Node.js، ويستخدم PowerShell الموجود في ويندوز. عند ظهور تحذير أمان، راجع السكربت قبل تشغيله.

## تشغيل بديل

من داخل المجلد: `py -m http.server 8080` ثم افتح http://localhost:8080/ .

## البيانات

يتم تخزين البيانات في IndexedDB داخل المتصفح، ولا تُرسل إلى خادم. احتفظ بنسخ احتياطية JSON بشكل دوري. الملفات الاحتياطية غير مشفرة. لا تفتح التطبيق من `file://` لأن بعض وظائف PWA تحتاج localhost أو HTTPS.

## الحالة

هذه نسخة محلية محسنة وليست التنفيذ الكامل لمتطلبات React/TypeScript ولا نسخة مالية إنتاجية مُختبرة بالكامل. راجع RELEASE_REPORT.md وTEST_REPORT.md.
